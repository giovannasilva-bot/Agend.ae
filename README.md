# Aplicativo de Agenda

## Sobre o projeto

O **Aplicativo de Agenda** é um projeto desenvolvido como parte da disciplina de Programação Orientada a Objetos, com o objetivo de criar um sistema de gerenciamento de atividades pessoais, permitindo que os usuários organizem seus compromissos, tarefas e lembretes de maneira prática e eficiente.

A aplicação consiste em um **backend desenvolvido em Python**, responsável por gerenciar os dados, controlar o acesso dos usuários e disponibilizar funcionalidades para a organização da rotina.

O sistema possui dois tipos de acesso: **Cliente** e **Administrador**.

### Funcionalidades

**Área do Cliente**
- Gerenciamento de agendas pessoais;
- Criação e organização de quadros;
- Cadastro, edição e gerenciamento de tarefas;
- Configuração de lembretes;
- Recebimento de alertas;
- Consulta ao histórico de atividades.

**Área do Administrador**
- Acompanhamento de métricas do sistema;
- Gerenciamento de administradores conforme seus níveis de acesso;
- Controle de permissões;
- Registro e auditoria de ações administrativas;
- Monitoramento de atividades e eventos de segurança.

### Tecnologias utilizadas

- **Python:** linguagem principal do projeto;
- **FastAPI:** desenvolvimento da API;
- **PostgreSQL:** gerenciamento do banco de dados;
- **JWT:** autenticação e controle de acesso;
- **Bcrypt:** proteção de senhas;
- **Pytest:** testes automatizados;
- **Ruff:** análise e padronização do código;
- **Mypy:** verificação de tipagem;
- **uv:** gerenciamento de dependências e ambiente do projeto.

### Conceitos de Programação Orientada a Objetos

O desenvolvimento aplica conceitos fundamentais de POO, como:

- Classes e objetos;
- Encapsulamento;
- Herança;
- Abstração;
- Relacionamentos entre classes;
- Decoradores e reutilização de código.

### Objetivo

O projeto busca oferecer uma solução que facilite a organização da rotina, contribuindo para o planejamento de atividades, o acompanhamento de tarefas e a redução de esquecimentos e desorganização. Além disso, permite aplicar conceitos de Programação Orientada a Objetos no desenvolvimento de uma aplicação estruturada e funcional.
